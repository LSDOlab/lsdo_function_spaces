# Basic Examples

Demonstrations of fundamental operations:

* **B-Spline Set Definition**: See `examples/basic_examples/simple_b_spline_set.py` for creating and evaluating multi-patch B-spline sets.
* **Topological Connectivity & Function Networks**: See `examples/basic_examples/ex_connectivity_network.py` for defining continuous seam and discrete markers, Gauss-Legendre quadrature interfaces, $C^0$/$C^1$ continuity conditions, automated CAD seam discovery, and SVD linear freedom analysis.
* **Bounding Enclosure Block**: Constructing 3D trivariate B-spline volumes enclosing complex geometry meshes.
